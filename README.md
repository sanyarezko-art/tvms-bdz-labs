# ТВиМС — БДЗ-1 и Лабораторные работы №1–4

**Вариант №16 · Миронов Артём Андреевич, ИКТ-23 · МИЭТ 2026**

Интерактивный сайт по курсу «Теория вероятностей и математическая статистика» с двумя режимами:

- **Презентация** — чистый красивый вид с задачами, решениями, формулами и графиками (для демонстрации).
- **Редактирование** — каждый блок кода можно редактировать и запускать прямо в браузере (Python через [Pyodide](https://pyodide.org/), как в Jupyter Notebook).

## Содержание

| Раздел | Содержание |
| --- | --- |
| **БДЗ-1** | 10 задач теории вероятностей (вариант 16) |
| **ЛР-1**  | Статистическая обработка одномерной выборки (n=50) |
| **ЛР-2**  | Моделирование N(16,16), R(16,32), E(3.2) и спец. распределения |
| **ЛР-3**  | Доверительные интервалы, критерий χ², гипотезы о распределении |
| **ЛР-4**  | Линейная регрессия, парная выборка (X, Y), n=50 |

## Запуск локально

```bash
cd site
python3 -m http.server 8080
# открыть http://localhost:8080
```
